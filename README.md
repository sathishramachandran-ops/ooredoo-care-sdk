# Ooredoo Care · Agent Platform Web SDK demo

A single-page demo host for the **Telco AI** multi-agent (Kore Agent Platform / Artemis,
Kore SE production workspace), themed to the Ooredoo Qatar look.

- Custom rich-card renderer over the official Web SDK (`/api/sdk/embed/script`)
- No sign-in gate — the **Demo identity** rail fills itself from Supabase
  (`telco-identify`) as soon as the customer types a registered mobile number in chat
- Records, status pills, option cards and a day-grouped slot picker are rendered
  client-side from the agent's Markdown

Demonstration build for evaluation purposes. Not affiliated with, and not endorsed by,
Ooredoo Q.P.S.C. Brand colours are used to illustrate theming only.
